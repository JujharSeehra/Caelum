# Caelum

Caelum is a carbon capture project focused on greatly improving the efficiency and economics of DAC through computational modelling, chemical simulations, and ML. 
This process uses NaOH and Ca(OH)2 in alkaline solutions to capture carbon dioxide through absorption. The captured CO2 is then processed through chemical reactors to create CaCO3!
The project combines:
* First-principles chemical and physical simulation
* Machine learning prediction
* Bayesian optimization
* Process and economic modelling
* Interactive Streamlit visualization
# How to use
Train the ML model found in release v1.0.0. This release also details instructions on how to quickly and easily view and train the ML model.
